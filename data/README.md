# Data & Telemetry Specification

Direktori ini memuat contoh skema data, dataset konfigurasi simulasi perangkat IoT, serta struktur telemetri log yang dihasilkan oleh platform **Black Door**.

---

## 📁 Struktur Data

1. **`iot-devices/`**: Definisi profil virtual IoT (nama perangkat, port layanan, tipe kerentanan yang disengaja, dan kredensial uji).
2. **`attack-telemetry/`**: Contoh log event penyerangan yang tertangkap oleh pengamat BeEF dan broker MQTT untuk evaluasi penilaian otomatis.
3. **`curriculum/`**: File referensi skenario pembelajaran, deskripsi misi, dan urutan *hint* bertingkat untuk AI Mentor.
